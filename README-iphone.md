# Carie AI iPhone 演示版

这是一个静态 PWA（渐进式网页应用）。要安装到 iPhone 主屏幕，必须先通过 HTTPS 网站访问；直接打开本地 `index.html` 不能完成 iOS 主屏幕安装，也不能启用离线缓存。

## 部署

将本文件夹内的完整文件上传到任意支持 HTTPS 的静态网站托管服务。请把 `index.html`、`manifest.webmanifest`、`sw.js` 和所有图标放在同一目录；不需要构建步骤。

## 安装到 iPhone

1. 在 iPhone 上用 Safari 打开已发布的 HTTPS 地址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。如果看到“作为网页 App 打开”，请保持开启。
4. 点击“添加”，再从主屏幕图标打开 Carie AI。
5. 在注册页面选择学生或导师身份，并用电子邮箱注册或登录。

## 云端数据库与 AI

配置云端数据库（Supabase）、邮箱验证码登录以及 AI 搜索 / AI 图片功能，请参阅 `SETUP.md`。未填写 `config.js` 时，应用以“本地模式”运行：账户和护照只保存在当前浏览器，邮箱不会验证，AI 功能关闭。
